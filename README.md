# E-Commerce Sales Analytics Dashboard

## Project Overview
This project focuses on analyzing e-commerce sales data using Microsoft Excel and Power BI to identify sales trends, customer behavior, and business insights.

## Tools Used
- Microsoft Excel
- Power BI

## Key Features
- Data Cleaning and Preparation
- Key Performance Indicator (KPI) Analysis
- Monthly Sales Trend Analysis
- Country-wise Sales Analysis
- Top 10 Products by Sales
- Top 10 Customers by Sales
- Order Status Analysis
- Interactive Dashboard Filters

## Dashboard Preview
The uploaded PDF file contains a visual preview of the Power BI dashboard.

## Project Files
- `Ecommerce_Sales_Analytics.pbix` – Power BI dashboard file.
- `E-Commerce Sales Analytics Dashboard.pdf` – Dashboard PDF preview.

## Key Performance Indicators
- Total Sales
- Total Orders
- Total Customers
- Average Order Value
- Total Quantity Sold

## Objective
To analyze e-commerce sales performance, identify important business trends, and present meaningful insights through interactive data visualization.
